# Product

## Register

product

## Users

Luis Coomer, sole operator of Vora Ventures. Uses this on a Mac Studio M4 Max, large monitor, dim environment, at any hour. Primary context: checking MRR progress, monitoring agent activity, reading Hermes logs. Power user — he built the system himself.

## Product Purpose

Internal command center for Vora Ventures. Centralizes MRR tracking across SparkCheck and Twitter Growth Optimizer, real-time agent run logs from the local Hermes/Ollama stack, and Hermes activity feeds. Success = Luis can read the health of his entire operation in under 10 seconds.

## Brand Personality

Precise, operational, confident. "Bloomberg meets Linear" — data density without chaos. The interface should feel like a tool that knows what it's doing.

## Anti-references

- Generic dark SaaS: purple gradients, glassmorphism, floating glow cards. The default "dark mode startup" aesthetic.
- Pure terminal/hacker: green on black, CRT scanlines, ASCII art. Too literal and performative.
- Corporate BI: Tableau/PowerBI gray, boxy, enterprise-bland, no personality.

## Design Principles

1. **Every pixel earns its place.** No decoration that doesn't carry information. Density is a feature, not a problem to solve.
2. **Data first, chrome second.** Typography and spacing serve the numbers. The numbers are the product.
3. **Operational confidence.** The interface should communicate that things are under control. No anxiety-inducing layouts, no ambiguous states.
4. **Speed over ceremony.** Luis should never wait for an animation to read a number. Motion is atmospheric, not transactional.
5. **Personal, not generic.** This is one person's control room. It can have opinions. It doesn't need to scale to a thousand users.

## Accessibility & Inclusion

WCAG AA contrast minimums on all text. Keyboard-navigable primary flows. Focus rings visible. No motion that blocks reading data.
